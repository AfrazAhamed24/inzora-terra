# Building Codes & Structural Requirements

## IBC 2021 Section 1604: Structural Design
- Buildings must withstand **design loads** (dead, live, wind, seismic)
- **Tilt threshold**: > 2 degrees from vertical requires immediate assessment
- **Material specifications**: concrete frame, masonry, steel each have load tables
- **Connection requirements** must resist calculated forces

## IBC 2021 Section 1605: Post-Disaster Assessment
- **Mandatory inspection** after any seismic event before re-occupancy
- **Red tagging**: structures unfit for habitation must be marked
- **Yellow tagging**: limited entry with supervision only
- **Green tagging**: structure assessed as safe for occupancy

## Applicability
- **Residential**: 1-3 story wood frame, concrete frame
- **Commercial**: multi-story, mixed use requires engineered assessment
- **All structures** post-event need visual + instrumental inspection
